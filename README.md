# 🐆 Adivinhe o Número

Jogo simples feito com **HTML, CSS e JavaScript** puro, em tema rosa claro com manchas de onça.
O sistema sorteia um número de 1 a 100 e você tenta acertar, recebendo a dica "é maior" ou "é menor" a cada chute.

👉 **Jogue online:** https://eduardacsantos.github.io/adivinhe-o-numero/

## Como jogar
1. Digite um número de 1 a 100 e clique em **Chutar** (ou aperte Enter).
2. Siga as dicas até acertar.
3. Veja em quantas tentativas você conseguiu e clique em **Jogar de novo**.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Como rodar localmente
Baixe o projeto e abra o arquivo `index.html` no navegador. Não precisa instalar nada.
